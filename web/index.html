🧠 Model Lifecycles, RAM Impact & Cloud vs. Local AI

Real-Time Process Data
⚡ Whisper Models: On-Demand Subprocesses (0 MB Idle)

Whisper models are NOT kept resident in RAM. The Swift daemons (whisper-pill ~42MB, meeting-recorder ~22MB) simply listen for hotkeys.

  • Live Slices: Spawns whisper-cli with base.en (~148 MB). Runs for ~180ms on Metal GPU, prints partial words, and immediately terminates.
  • Final Pass / Meetings: Spawns whisper-cli with large-v3-turbo (~1.6 GB). Runs for ~1.2s, saves output, and immediately terminates.
  • Zero Memory Leak: macOS kernel immediately reclaims all memory and GPU textures upon process exit.
🛡️ Zero Audio Leaves Device (Cloud vs Local AI)

Is Gemini used during audio recording? NO. Audio capture and speech-to-text are 100% private and on-device via Apple Silicon Metal GPU.

  • Text-Only Summarization: After Whisper outputs plain text, summarize_meeting.py queries Tier 1: Gemini for executive insights.
  • Offline Fallback: If Gemini is unreachable or times out (25s), it queries Tier 2: LM Studio (qwen2.5-coder-7b) locally on port 1234.
  • LM Studio Memory: Qwen 7B remains loaded in Unified Memory (~4.35 GB) as long as LM Studio is open, providing instant 3-second offline synthesis.
